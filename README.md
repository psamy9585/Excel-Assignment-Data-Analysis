Excel Data Exploration – Product Dataset

🔎 Project Overview
This repository showcases data exploration and analysis in Microsoft Excel using a structured product dataset.  
The project demonstrates how to apply summarization, logical functions, conditional aggregation, and text manipulation — all core skills for preparing datasets for deeper analytics and visualization.

---

📁 Dataset
The dataset includes product details such as:
- Product ID (date + country code)
- Product Name
- Brand Name
- Price ($)
- Quantity
- Category

---

🧮 Key Tasks
- Basic Exploration → SUM, COUNT, AVERAGE  
- Min & Max Values → MIN, MAX  
- Price Classification → IF function for High vs Standard price  
- Conditional Aggregation → SUMIF for Electronics, COUNTIF for products < $100  
- Text Extraction → LEFT, RIGHT, MID for Day, Country Code, Month  

---

🎯 Learning Outcomes
- Built proficiency in Excel formulas for data summarization  
- Applied logical functions for classification  
- Used conditional functions for targeted analysis  
- Practiced text manipulation for structured data extraction  
- Strengthened foundation for data cleaning and preparation

---

🛠️ Tools & Techniques
- Microsoft Excel  
- Functions: SUM, COUNT, AVERAGE, MIN, MAX, IF, SUMIF, COUNTIF, LEFT, RIGHT, MID 
- Build Pivot Tables & Charts for visualization  
- Extend analysis with Python (Pandas, NumPy)  
- Integrate with Power BI for dashboards
